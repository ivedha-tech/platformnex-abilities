# Security

## Reporting a vulnerability

Do not open a public issue. Use **Security > Report a vulnerability** on the
affected repository (private vulnerability reporting), or email the security
contact listed in the organisation profile.

We acknowledge reports within 2 working days and aim to fix by severity:
Critical 7 days, High 30 days, Medium 90 days.

## If you are staff and suspect an incident

Post in the incident channel and page the security lead now. Then open an
issue with the `incident` label. Details: handbook, incident response policy.
