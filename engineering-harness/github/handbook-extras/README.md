# Engineering handbook

How we take work from idea to production, and the policies behind it.

- `docs/` start with `01-operating-model.md`; new joiners start with `04-onboarding.md`
- `policies/` approved organisational policies
- `compliance/` control matrix, evidence plan, risk and vendor registers
- `templates/` idea brief, PRD, ADR, threat model, privacy assessment, release checklist, runbook, postmortem

Everything here changes by pull request. Policy changes need the policy
approver's review (see `.github/CODEOWNERS`); the merged PR is the approval record.
